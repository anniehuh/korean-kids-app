Lesson 2: Learn 가, 나, 다, 라, 마

In this lesson, we will learn five Korean consonants and combine them with the vowel ㅏ.

Step 1: Meet the Consonants

These are the consonants we will learn today.

ㄱg / k sound
ㄴn sound
ㄷd / t sound
ㄹr / l sound
ㅁm sound

Step 2: Add the Vowel ㅏ

The vowel ㅏ makes the sound ah.

consonant + vowel = syllable

ㄱ + ㅏ = 가 (ga)

ㄴ + ㅏ = 나 (na)

ㄷ + ㅏ = 다 (da)

ㄹ + ㅏ = 라 (ra)

ㅁ + ㅏ = 마 (ma)

Step 3: Read the Syllables and Learn Their Meanings

Look at the silly baby hippo picture cards to help remember each syllable.

가

가 = go
🏃 가! = Go!
🎒 가방 = bag
👨‍👩‍👧 가족 = family

나

나 = I / me
🙂 나 = me
🌳 나무 = tree
🦋 나비 = butterfly

다

다 = all / together
👨‍👩‍👧‍👦 다 = all
🐿️ 다람쥐 = squirrel
🦵 다리 = leg / bridge

라

라 → 나라 = nation / country
🗺️ 나라 = nation
🍜 라면 = ramen
🎵 라 = la

마

마 → 마마 = mommy
👩 마마 = mommy
✨ 마법 = magic
🏘️ 마을 = village
