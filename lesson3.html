Lesson 3: Learn 바, 사, 아, 자, 차

In this lesson, we will learn more Korean syllables with the vowel ㅏ.

Step 1: Meet the Sounds

These are the Korean letters we will use today.

ㅂ b / p sound
ㅅ s sound
ㅇ silent start
ㅈ j sound
ㅊ ch sound

Step 2: Add the Vowel ㅏ and READ the Syllables

The vowel ㅏ makes the sound ah.

consonant + vowel = syllable

ㅂ + ㅏ = 바 (ba)

ㅅ + ㅏ = 사 (sa)

ㅇ + ㅏ = 아 (a)

ㅈ + ㅏ = 자 (ja)

ㅊ + ㅏ = 차 (cha)

Step 3: See how the Syllables are Used in Context

Look at the baby hippo and baby panda picture cards to help remember each syllable.

바

바 → 바다 = sea
🌊 바다 = sea
🧺 바구니 = basket
🍚 밥 = rice / meal

사

사 → 사과 = apple
🍎 사과 = apple
🦁 사자 = lion
👤 사람 = person

아

아 = ah / 아기 = baby
👶 아기 = baby
💛 아빠 = dad
😮 아! = Ah!

자

자 = sleep / 자요 = sleeps
😴 자요 = sleeps
📏 자 = ruler
🚲 자전거 = bicycle

차

차 = car / tea
🚗 차 = car
🍵 차 = tea
🅿️ 주차 = parking
