Lesson 13: Learn 고, 노, 도, 로, 모

In this lesson, we will combine Korean consonants with the vowel ㅗ. The vowel ㅗ makes an “oh” sound.

Step 1: Meet the Sounds

These are the syllables we will learn today.

고 go
노 no
도 do
로 ro
모 mo

Step 2: Add the Vowel ㅗ and Read the Syllables

The vowel ㅗ sounds like “oh.” When we add ㅗ to consonants, we can read new syllables.

ㄱ + ㅗ = 고

ㄴ + ㅗ = 노

ㄷ + ㅗ = 도

ㄹ + ㅗ = 로

ㅁ + ㅗ = 모
