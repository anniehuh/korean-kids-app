Lesson 17: Learn 기, 미, 비, 시, 이

In this lesson, we will combine Korean consonants with the vowel ㅣ. The vowel ㅣ makes an “ee / i” sound.

Step 1: Meet the Sounds

These are the syllables we will learn today.

기 gi
미 mi
비 bi
시 si
이 i

Step 2: Add the Vowel ㅣ and Read the Syllables

The vowel ㅣ sounds like “ee” or “i.” When we combine consonants with ㅣ, we can read new syllables. The consonant ㅇ is silent at the beginning, so 이 sounds like “i / ee.”

ㄱ + ㅣ = 기

ㅁ + ㅣ = 미

ㅂ + ㅣ = 비

ㅅ + ㅣ = 시

ㅇ + ㅣ = 이

Step 4: Reading Practice

Read this tiny story using words from Lesson 17.

이름을 써요. We write a name.
비가 와요. Rain comes.
기차를 타요. We ride a train.
비행기를 타요. We ride an airplane.
미역국을 먹어요. We eat seaweed soup.
이제 시작해요. Now we start.
