Lesson 11: Learn 거, 너, 더, 러, 머

In this lesson, we will combine Korean consonants with the vowel ㅓ. The vowel ㅓ makes an “uh / eo” sound.

Step 1: Meet the Sounds

These are the syllables we will learn today.

거 geo
너 neo
더 deo
러 reo
머 meo

Step 2: Add the Vowel ㅓ and Read the Syllables

The vowel ㅓ sounds like “uh” or “eo.” When we add ㅓ to consonants, we can read new syllables.

ㄱ + ㅓ = 거

ㄴ + ㅓ = 너

ㄷ + ㅓ = 더

ㄹ + ㅓ = 러

ㅁ + ㅓ = 머

Step 4: Reading Practice

Read this tiny story using the syllables from Lesson 11.

거미 가요. The spider goes.
나 너 봐요. I see you.
우리 다 더 주세요. Please give us all more.
나라 이름 러시아. The country name is Russia.
마마 머리. Mommy’s hair.
