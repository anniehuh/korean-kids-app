Lesson 15: Learn 구, 누, 두, 무, 수

In this lesson, we will combine Korean consonants with the vowel ㅜ. The vowel ㅜ makes an “oo / u” sound.

Step 1: Meet the Sounds

These are the syllables we will learn today.

구 gu
누 nu
두 du
무 mu
수 su

Step 2: Add the Vowel ㅜ and Read the Syllables

The vowel ㅜ sounds like “oo” or “u.” When we combine consonants with ㅜ, we can read new syllables.

ㄱ + ㅜ = 구

ㄴ + ㅜ = 누

ㄷ + ㅜ = 두

ㅁ + ㅜ = 무

ㅅ + ㅜ = 수

Step 4: Reading Practice

Read this tiny story using words from Lesson 15.

누나가 구두를 신어요. Older sister puts on shoes.
누나가 가게에 가요. Older sister goes to the store.
두부가 있어요. There is tofu.
무가 있어요. There is a radish.
수박도 있어요. There is watermelon too.
누나가 수박을 먹어요. Older sister eats watermelon.
